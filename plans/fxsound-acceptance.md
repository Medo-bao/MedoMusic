# FxSound 复原验收记录

当前状态：已按用户明确确认的“五项音效与十段均衡器”范围完成复原和验收（2026-09-23）。

## 已验证的处理链

- 五项音效：清晰度、环境、环绕、动态、低音。
- 十段均衡器：原始系数生成、增益／频率变化、旁路和历史状态。
- 原始必要增益、峰值处理、Music2 参数映射。
- 单声道、立体声、四声道、5.1、7.1 分配与格式切换。
- 高采样率内部转换、非整组缓冲区末尾、静音状态保留。
- 应用内 JavaScript AudioWorklet 实现，不加载 FxSound DLL／驱动。

合成音乐是确定性生成的鼓、低音、和弦及旋律组合，不是录音素材。
实时测试保留 Chromium currentFrame 的重复／修正记录；同一测试位置没有编号信号或效果样本错误，不能把时钟标签异常直接当作音频数据断帧。
这些证据不包含物理音频接口的环回测量。
